# Blups

Blups is a casual and short 2D mobile game in which a new minigame appears to be played every 10 seconds. This game has been heavily inspired by Pureya. It can be played in the browser, in windows or in mobile devices. This is the first real mobile game that I develop, even though I decided not to upload it to the play store.

![](Gifs/blups-game.gif)

I learned a lot when making this game. It was a real challenge at the time to get all the minigames working and changing between them, as well as finding a cohesive style. The main goal was learning and getting used to working with the Unity Engine and C#, as well as learning how to make a mobile game with Unity.
